# trading212/records/ 目录说明

## 1. 职责

Trading 212 账户的**记账归档**：把券商愿意给的每一条记录，原样存下来。

「原样」是硬性的——字段不删、不改名、不四舍五入。被整理过的记录回答不了整理者
当初没想到的问题，而这些文件的用途恰恰是将来回答现在想不到的问题。

**这些文件不入库。** 本仓库是 public 的，而这里存着持仓、成交、现金流和账户号，
故本目录带自己的 `.gitignore`，只有该文件与本说明进版本管理。

## 2. 文件清单

写入方为 `trading212/archive.py`（券商记录）与 `trading212/dashboard/snapshots.py`
（资产曲线）。除下表外本目录不应出现其他文件。

| 文件 | 内容 | 去重键 |
|---|---|---|
| `orders.jsonl` | 成交明细，**一行一笔成交**（不是一行一个订单）：完整 order 对象 + 完整 fill 对象，含 `walletImpact` 的逐项税费、汇率与已实现盈亏 | `fill_id` |
| `transactions.jsonl` | 资金流水：入金、出金、费用、利息 | `reference` |
| `dividends.jsonl` | 分红，含每股金额与账户币种金额 | `reference` |
| `positions.jsonl` | 持仓快照，每次采集追加一行 | 无（时间序列） |
| `account_summary.jsonl` | 账户快照，每次采集追加一行 | 无（时间序列） |
| `signals.jsonl` | **每次决策一行**：目标持仓、意向、风控结果、提交结果、决策前账本 | 无（时间序列） |
| `equity/live_snapshot.json` | 最新一次采样的完整快照 | 原子替换 |
| `equity/samples/YYYY-MM-DD.jsonl` | 逐笔采样，看板短跨度曲线的来源 | 追加 |
| `equity/daily.jsonl` | 按日汇总（开高低收 + 笔数），看板长跨度曲线的来源 | 每日一行 |

一行一笔成交而非一行一个订单：一个订单可以分多次成交，每笔成交有自己的价格、
时刻与税费，能独立回答问题的是成交而不是订单。

## 3. 子目录索引

| 子目录 | 内容 |
|---|---|
| `equity/` | 资产曲线的采样与日汇总 |

## 4. 依赖关系

只被写入，不被 import。读取方：`trading212/dashboard/api.py`（看板展示）。
路径由 `common/paths.records_dir("t212")` 给出，业务代码不自行拼接。

## 5. 产出与清理

`equity/samples/` 可以按需删除，只损失短跨度曲线的细节，日汇总不受影响。

**其余文件不要删**：`orders.jsonl` 与 `transactions.jsonl` 是账户历史的本地副本，
券商的 API 只能翻到它愿意给的深度，删掉之后不保证能重新取回。

## 6. 变更记录

2026-08-23 建立。用户要求把所有记账数据放在 `trading212/` 下，遂以本目录承载，
并配 `.gitignore` 防止推上公开仓库。首次采集取回 546 笔成交、272 条流水、42 条分红。
