# `.agents/` 目录说明

## 1. 职责

存放 Codex 在本项目内自动发现的技能。项目纪律在根目录 `AGENTS.md`，跨会话状态在
`WORKING_MEMORY.md`，均不放在本目录。

## 2. 文件清单

| 文件名 | 作用 | 存在必要性 | 谁在用 |
|---|---|---|---|
| `README.md` | 说明本目录职责、依赖与清理规则 | 删除后本目录违反项目目录说明纪律 | 修改或审查本目录的会话 |

本目录没有其他直属文件。

## 3. 子目录索引

| 子目录 | 内容 | 说明文件 |
|---|---|---|
| `skills/` | 从 `.claude/skills/` 迁移并适配为 Codex 引用的 10 个项目技能 | `skills/README.md` |

## 4. 依赖关系

本目录由 Codex 的技能发现机制读取，不被项目代码 import。技能以 `AGENTS.md` 为上位纪律。

## 5. 产出与清理

本目录只含长期技能与说明文档，不产生运行时文件。10 个技能须与 Claude 原件保持流程等价，
仅允许把代理专属路径和文件名适配为 Codex 对应项。
