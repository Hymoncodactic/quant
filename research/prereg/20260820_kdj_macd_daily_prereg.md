# 预注册：KDJ 信号 + MACD 筛选，美股科技股日频做多

冻结时间：2026-08-20（本文件在任何回测代码运行之前写定）
对应裁定：`research/decisions/20260820_kdj_macd_daily_ruling.md`

## 1. 研究问题

在美股科技股日线上，以 KDJ 低位金叉为入场信号、MACD 多头排列为筛选条件、
KDJ 死叉为出场的纯多头规则，其逐笔胜率是否显著高于同持有期的无条件基准。

本轮只回答胜率问题，不回答该规则是否具备可交易的风险调整后收益。

## 2. 口径（全部先于运行写定，运行中不得修改）

### 2.1 指标定义

KDJ，参数 (9, 3, 3)：

    RSV_t = (C_t - LLV(L,9)_t) / (HHV(H,9)_t - LLV(L,9)_t) * 100
    K_t   = (2/3) * K_{t-1} + (1/3) * RSV_t
    D_t   = (2/3) * D_{t-1} + (1/3) * K_t
    J_t   = 3*K_t - 2*D_t

初值 K_0 = D_0 = 50。分母为零（9 日内最高等于最低）时 RSV 取 50，
并统计该情形的发生次数写入结果文件。

MACD，参数 (12, 26, 9)：

    EMA_n 递推系数 alpha = 2/(n+1)，以序列首值为种子
    DIF_t = EMA12(C)_t - EMA26(C)_t
    DEA_t = EMA9(DIF)_t
    HIST_t = 2 * (DIF_t - DEA_t)

### 2.2 预热

每个标的序列前 200 根 bar 只用于指标递推，不产生任何信号。
依据：K/D 递推的初值权重按 (2/3)^n 衰减，n=200 时为 5e-36；
EMA26 种子权重按 (1-2/27)^n 衰减，n=200 时为 3e-7。两者均已低于浮点噪声量级。

### 2.3 入场条件（在第 t 个交易日收盘后判定）

同时满足四条：

1. K_t > D_t 且 K_{t-1} <= D_{t-1}（K 上穿 D）
2. K_t < 30
3. DIF_t > DEA_t
4. DIF_t > 0

且该标的当前无持仓。

### 2.4 出场条件（在第 s 个交易日收盘后判定，s > 入场信号日 t）

K_s < D_s 且 K_{s-1} >= D_{s-1}（K 下穿 D）。

### 2.5 成交时序

主口径：信号在第 t 日收盘后判定，成交在第 t+1 日**开盘价**。
出场同理，信号在第 s 日收盘后判定，成交在第 s+1 日开盘价。

理由：`/backtest-discipline` §二.1、§二.2 的保守默认，禁止同 bar 成交、
禁止用当根收盘价成交。

样本末端未平仓的持仓：单独计数，不计入胜率分母，不做强制平仓假设。

### 2.6 成本

滑点与手续费一律置零（用户本轮明言的要求，S6）。
该项**偏离** `/backtest-discipline` §二.3 与 §二.4 的保守默认，
偏离方向对策略有利，裁定与报告须在结论限定节显式声明。

### 2.7 标的池与样本期

标的：NVDA、AAPL、MSFT、META、AMD（本地 `data/t212/curated/us_equity/` 已有日线，
Yahoo 源，`auto_adjust=True` 已按拆股与分红复权）。

窗口 W1（主口径）：2016-01-01 至 2026-08-19。
窗口 W2（对照）：各标的全部可得历史至 2026-08-19。

两个窗口分别独立报告，禁止在两者之间择优后只报其一。

### 2.8 胜率定义

单笔收益率 = 出场成交价 / 入场成交价 - 1。
胜 = 收益率 > 0。收益率恰为 0 计入负例（保守）。
胜率 = 胜的笔数 / 已平仓笔数。

## 3. 基准与判据（先于运行冻结）

### 3.1 必备基准：同持有期无条件胜率

对每一笔策略交易，取其持有交易日数 h，在同一标的、同一窗口内计算
全部长度为 h 的重叠持有期（以次日开盘买入、h 个交易日后开盘卖出的口径）
的正收益比例，作为该笔交易的无条件基准胜率。全部交易的基准取按笔平均。

理由：科技股在样本期内整体上行，任意随机入场的胜率本身就显著高于 50%。
不与同持有期基准比较，胜率数字没有任何判别力。

### 3.2 判定标准

| 判定 | 条件 |
|---|---|
| 通过 | 策略胜率减去同持有期基准胜率 >= 5 个百分点，且单边二项检验 p < 0.05，且 W1 与 W2 同向 |
| 探索性通过 | 差值 >= 5 个百分点但 p >= 0.05，或两窗口方向不一致 |
| 不通过 | 差值 < 5 个百分点，或方向为负 |

已平仓笔数少于 30 笔的标的单独列出，其单标的结论一律标为样本不足，不参与定级。

### 3.3 无未来函数三件套

- 断言：第 t 日信号的全部输入 bar 的时间戳严格小于等于 t，成交 bar 的时间戳严格大于 t。
  写成运行时断言，逐笔在线检查。
- 故意前视对照臂 A-LOOKAHEAD：把全部指标序列整体前移一期（第 t 日使用第 t+1 日的
  K/D/DIF/DEA），其余不动。判别力要求：该臂胜率须显著高于主臂；
  若两者接近，说明本检验无判别力，须更换检验方式后重跑。
- 特征可测性：K、D、J、DIF、DEA 全部只由第 t 日及之前的 open/high/low/close 递推得到，
  无全样本统计量、无跨标的信息、无当日之后的价格。

### 3.4 对照臂清单

| 臂 | 与主臂的唯一差异 |
|---|---|
| A-MAIN | 无（主口径） |
| A-LOOKAHEAD | 指标整体前移一期（前视对照，仅用于检验判别力） |
| A-CLOSE-FILL | 成交价改用信号当日收盘价（贴近手工看盘的口径） |
| A-NOMACD | 去掉 MACD 两条筛选，只留 KDJ 低位金叉 |
| A-NOK30 | 去掉 K<30 限制，只留 K 上穿 D 与 MACD 筛选 |

A-NOMACD 与 A-NOK30 用于归因：MACD 筛选与低位限制各自贡献多少胜率，
禁止把全部增量归给其中一项（`/backtest-discipline` §四.4）。

## 4. 本轮不做的事

- 不做参数寻优。(9,3,3) 与 (12,26,9) 为固定值，不扫描。
- 不做 walk-forward。本规则无需训练参数，按 `/backtest-discipline` §三.1 可全样本回测。
- 不出年化收益率、夏普、最大回撤等业绩指标。本轮只交付胜率与收益率分布，
  资金占用口径未定义，业绩率无法按 `/backtest-discipline` §五.1 正确计算。
- 不做仓位管理与多标的组合。每个标的独立成交，单标的同时最多一笔持仓。

## 5. 已知偏差（先于运行登记）

1. 幸存者偏差：5 个标的是在 2026-08-20 从当前存续的大市值科技股中挑出的，
   样本期内退市或长期落后的科技股不在池内。该偏差方向对策略有利。
2. 成本为零（§2.6）。
3. 复权价陷阱：数据为分红与拆股复权后的价格序列，指标在复权价上计算，
   与在原始价格上手工看盘所得的 K/D 数值不完全相同，历史越久差异越大。
4. Yahoo 为非授权页面接口，无数据质量承诺（`data/t212/curated/DATA_SPEC.md` §1）。
