# 预注册：B0 统计套利配对策略

冻结时间：2026-08-23 01:4x（本文件落盘早于任何配对统计量的计算）
研究目录：`research/b0_statarb/`
配对裁定：`research/decisions/20260823_b0_statarb_ruling.md`（结果产出后写）

## 0. 立项与硬约束

用户要求：开发 B0，统计套利配对策略（价差回归、z-score），标的取美股流动性好且
Trading 212 可交易者。

### 0.1 决定性约束：T212 Invest 不能做空

| 证据 | 来源 |
|---|---|
| 卖单数量超过持仓即被拒，理由 `selling_equity_not_owned` | `backtest/t212/admission.py:126-131` |
| API 卖单语义为「quantity 传负数」，且以持仓为前提 | `data/reference/t212_openapi_v0_20260820.yaml` Selling Orders 节 |

经典配对交易（做多低估腿、做空高估腿）**在 T212 Invest 账户上不可执行**。
本预注册据此把策略拆成三个变体，其中只有两个可实盘。

### 0.2 用户提出的「负相关同时做多即对冲」

该提法属**分散化**，不是统计套利。且本项目已实证否定其前提：
`research/notes/20260819_negative_correlation_findings.md` §一——28 组大盘股两两相关性
全部为正（均值 +0.271，最小 +0.083），唯一稳定负相关的工具是机械反向类，
年持有损耗 16%~69%。本轮**不重复该已被证伪的方向**，改做真正的配对回归。

## 1. 先验立场（动手前写定）

1. 预期配对回归在 502 只 S&P500 成分股上**存在但已显著衰减**。依据：
   Gatev-Goetzmann-Rouwenhorst (2006) 1962-2002 年化超额约 11%；
   Zhu (2024, Yale) 用 2003-2023 复现，最保守设定下年化超额 6.2%、夏普 1.35。
2. 预期**长仓限制会吃掉大部分超额**。经典配对的收益来自价差收敛，长仓变体
   只能吃到收敛的一半，且被迫承担全部市场 beta。
3. 预期**成本是主要杀手**。配对策略换手远高于 A0（A0 双边 5.1 倍/年），
   T212 的 0.15% 双边换汇费对高换手策略极不友好。
4. 预期 B0 与 A0 **负相关或低相关**。依据：Zhu (2024) 发现动量因子 1 个标准差
   的上升即可抹平配对交易收益，而 A0 是 TSMOM 动量策略。若成立，B0 即使
   独立表现平庸，作为 A0 的分散器仍有价值。
5. **预期大部分实验会失败，失败结果同样入档**（P2）。

## 2. 标的池（冻结）

502 只：S&P 500 成分股（Wikipedia，2026-08-23 取回）∩ T212 可交易美股
（`data/reference/t212_instruments_20260821.json`，type=STOCK / USD / `_US_EQ`）。
503 只中仅 TPR 不可交易。GICS 行业与子行业随同冻结，127 个子行业，
其中 73 个含 ≥3 只标的。

**已知限定**：当前成分股名单带指数存活者偏差（退市与被剔除者不在池内），
方向对策略有利。GGR 用全 CRSP 池避免该偏差，本轮不具备该数据。

## 3. 方法（冻结）

### 3.1 配对选择（两种，并列跑，不择优）

| 代号 | 方法 | 规则 |
|---|---|---|
| S-DIST | 距离法（GGR 2006） | 形成期内价格归一化为累计收益，取欧氏平方距离最小的前 N 对 |
| S-COINT | 协整法（Engle-Granger 两步） | 对 (A,B) 回归得对冲比 β，残差做 ADF，p < 0.05 判协整；按 ADF p 值取前 N 对 |

两种方法**都只在同一 GICS 子行业内配对**（Do & Faff 2010：同业配对收益最高），
并同时跑一个跨行业对照臂以检验该限制是否真的有益。

### 3.2 时间切分（冻结）

形成期 12 个月 → 交易期 6 个月，滚动前推，互不重叠（GGR 标准）。
形成期只用于选对与估参数，交易期只用于评估。**跨期不复用任何参数**。

### 3.3 信号（冻结）

价差 = A − β·B（S-COINT）或归一化价差（S-DIST）。
z = (spread − μ_formation) / σ_formation，μ 与 σ **只取自形成期**。

| 事件 | 条件 |
|---|---|
| 开仓 | z 穿越 ±2.0 |
| 平仓 | z 回到 0（穿越） |
| 强制平仓 | 交易期结束 |
| 止损 | z 达到 ±4.0（预注册为必选，防不收敛腿） |

### 3.4 三个变体

| 代号 | 说明 | T212 可执行 |
|---|---|---|
| MN | 市场中性：多低估腿、空高估腿，等金额 | **否**，仅作参照，用于量化长仓限制的代价 |
| L1 | 长仓轮动：只持低估腿，z 翻转即换到另一腿，始终满仓其一 | 是 |
| L2 | 长仓择时：\|z\|>2 时持低估腿，否则持现金 | 是 |

### 3.5 成本与口径

按 `/backtest-discipline`：t 日信号、t+1 成交，成交价用次 bar 开盘或
`same_close` 口径（与 A0 一致，两档并列）；费率取 T212 actual 与 worst 两档；
年化因子 252；无风险利率 0。

## 4. 判定标准（一个「发现」成立须同时满足）

| # | 条件 |
|---|---|
| C1 | 交易期（样本外）年化超额收益 > 0，且经 Newey-West(20) 检验 t > 2.0 |
| C2 | 扣除 T212 actual 档全部成本后 C1 仍成立 |
| C3 | 分半样本（前半 / 后半时间）同号，且两半均为正 |
| C4 | 对入场阈值 z ∈ {1.5, 2.0, 2.5} 与形成期 ∈ {6, 12} 个月不翻转结论 |
| C5 | 与 A0 日收益相关性 < 0.3（正交性硬门槛） |

分级：全部满足为**成立**；满足 C1-C2 但 C3/C4 不稳为**探索性**；
C1 或 C2 不过为**否决**。

## 5. 实验清单（含预期）

| # | 实验 | 预期 |
|---|---|---|
| E1 | S-COINT × MN 全样本 | 正收益，年化 3%~8%，是上界 |
| E2 | S-COINT × L1 | 显著低于 MN，可能为负 |
| E3 | S-COINT × L2 | 介于两者之间，波动更低 |
| E4 | S-DIST × 三变体 | 弱于 S-COINT（文献：距离法选不出稳健收敛对） |
| E5 | 同业 vs 跨行业配对 | 同业更优（Do & Faff） |
| E6 | 成本敏感性：0 / actual / worst | worst 档大概率转负 |
| E7 | 与 A0 的相关性与合成组合 | 负相关或低相关 |
| E8 | 参数敏感性 C4 扫描 | 不翻转 |

## 6. 预注册的怀疑点（结果回来后逐条回答）

| # | 怀疑 |
|---|---|
| D1 | 长仓变体是否还算「统计套利」？若 L1/L2 的收益主要来自市场 beta 而非价差收敛，应判为伪配对，须用对市场的回归系数检验 |
| D2 | 指数存活者偏差能解释多少收益？无法直接检验，须在结论中标注为未证实的上偏来源 |
| D3 | 形成期估的 β 在交易期是否漂移？须报交易期内 β 的稳定性 |
| D4 | 换手率与成本：配对策略换手远高于 A0，T212 的 0.15% 双边换汇费是否直接吃掉全部超额 |
| D5 | 2026 年的美股是否已因量化拥挤而无价差可套？须看分年收益是否单调衰减 |
| D6 | z-score 用形成期 μ/σ，若交易期波动制度改变，阈值失去意义 |

## 7. 采纳规则（进入实盘候选须全部满足）

| 规则 | 内容 |
|---|---|
| R1 | 判定标准 C1-C5 全部满足 |
| R2 | actual 档扣费后年化超额 > 2%（低于此不值得占用资金与注意力） |
| R3 | 最大回撤不超过 A0 同期的 1.5 倍 |
| R4 | 收益来源可用一句话讲清，且与 A0 的动量来源不同源 |
| R5 | 换手率在 T212 的最小订单值与碎股约束下可执行 |

未满足 R1-R5 者，按实际达成度记为「探索性」或「否决」，**不修改标准去迁就结果**（P1）。
