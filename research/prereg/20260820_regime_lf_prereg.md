# 预注册：高频信息状态层 + 低频信号层，美股科技股组合

冻结时间：2026-08-20 16:0x（先于搜索网格的任何一次运行）
对应裁定：`research/decisions/20260820_regime_lf_ruling.md`
代码：`research/regime_lab/`

## 1. 研究问题与目标判据

用户设定的目标（S6）：验证期年化收益 >= 30% 且最大回撤 <= 20%，
零手续费零滑点（S6，信号层验证），非高频（小时及以下决策频率）。
本轮回答：在冻结的策略家族内，是否存在配置在**未参与选择的验证期**上同时达到
该目标，并通过多重检验校正后仍有统计学依据。

明示立场（先于结果写定）：目标是**待检验的验收线**，不是承诺。若无配置达标，
如实裁定不通过；禁止为凑数而追加家族成员或改判据。

## 2. 数据与「高频状态层」的合法性

- 交易池：本地 18 只美股科技股（TECH18，`regime_lab/data.py`），T212 可交易。
  状态变量与基准：QQQ（本地 us_etf，仅研究用）。
- 日线全历史（复权，Yahoo）；小时线仅最近 730 天，5 分钟仅 60 天，1 分钟仅 30 天。
- **小时及以下的历史深度不足以对小时频信号做独立验证**（730 天 ≈ 500 交易日），
  故本轮的「高频信息」以**已验证的日线代理**进入状态层：Yang-Zhang(20d) 对
  小时线已实现波动率（含隔夜项）在 711 个重叠交易日上 Pearson 0.93~0.98、
  70 分位应激分类一致率 0.87~0.97、均值几乎无偏
  （`regime_lab/results/rv_proxy_validation.csv`，S5 实证）。
  状态层因此可在几十年历史上运行且语义等价于 HF 已实现波动率状态。
- 若日后购买深度小时级历史（Polygon/Databento 等），状态层可无缝换成真实 RV。

## 3. 冻结的策略家族（450 个配置，运行中禁止增删）

配置 = (收益流, 信号, 波动状态闸, 市场趋势闸, 波动目标)，全笛卡尔积 3×5×5×2×3。

| 维度 | 取值 | 定义（全部以 t-1 收盘可得信息决策，作用于 t 日收益） |
|---|---|---|
| 收益流 | cc / on / id | 持有（昨收→今收）/ 仅隔夜（昨收→今开）/ 仅日内（今开→今收） |
| 信号（分标的） | always / tsmom252 / tsmom126 / ma200 / ma100 | 恒满仓 / C(t-1)>C(t-1-L) / C(t-1)>=SMA_L(t-1) |
| 波动状态闸（市场级） | none / p70x0 / p70x50 / p80x0 / p80x50 | QQQ 的 YZ20 处于其**因果扩展历史**（>=756 观测）的 70/80 分位以上时，全组合敞口 ×0 或 ×0.5 |
| 市场趋势闸 | off / qqq200 | QQQ 收盘 < SMA200 时全组合敞口 ×0 |
| 波动目标（分标的） | off / vt15 / vt20 | 敞口 = min(1, 目标年化σ / YZ20_{t-1})，无杠杆（上限 1） |

组合构造：当日可用标的（已上市且历史 >= 260 bar）等资本槽位；
槽内权重 = 信号 × 波动目标 × 两道闸的乘积，上限 1；未用部分现金收益 0。
无做空、无杠杆（英国零售账户现实约束）。

## 4. 两段式与选择规则（冻结）

| 段 | 期间 | 用途 |
|---|---|---|
| S | 2000-01-03 ~ 2017-12-29 | 全家族 450 配置，按下列规则机械选择 |
| V | 2018-01-01 ~ 2026-08-19 | 只对入围配置定级 |

选择规则：S 段 Calmar（CAGR/最大回撤）降序取前 5，同一收益流最多 2 个；
纯基准配置 cc|always|none|off|off 不可入围（它就是 EW18 买入持有对照，
且其 S/V 指标在冻结前已被查看，见 §7）。

## 5. 定级判据（冻结，对每个入围配置独立执行）

| 判据 | 内容 |
|---|---|
| 目标判据 | V 段 CAGR >= 30% 且 V 段最大回撤 <= 20%（复利日净值曲线，本金口径 = 满配 1.0，年化因子 252，rf=0） |
| 统计判据 A | SPA 一致 p < 0.05（Hansen 2005，S 段全家族 450 对 EW18 基准，平稳 bootstrap 均块长 20d，B=2000） |
| 统计判据 B | DSR > 0.95（Bailey-López de Prado 2014，V 段入围配置日收益，N=450，试验夏普方差取 S 段全家族横截面） |
| 通过 | 目标判据 ∧ A ∧ B |
| 探索性通过 | 目标判据成立，A/B 至少一项不成立 |
| 不通过 | 目标判据不成立 |

强制报告（不定级）：V 段 CAGR 与 MaxDD 的平稳 bootstrap 90% CI；
**存活者对照**——同一配置结构套在 QQQ 单资产上的 V 段指标（无存活者偏差的那条线）；
EW18 与 QQQ 买入持有并列；逐年收益、敞口均值、年换手、闸切换次数、
2020-02~03 与 2022 全年的回撤行为；家族 S→V Calmar 的 Spearman 秩相关
（搜索过拟合诊断）。

## 6. 无未来函数三件套

- 全部决策输入统一 shift(1)，验收含「去掉 shift 的作弊臂必须显著更好」的
  判别力检验（实测 +20.1% 年化，`regime_lab/acceptance.py` 7/7 通过）。
- 信号与状态闸的前缀重算因果性检验（截断未来后 t 日取值逐位不变）。
- SPA 与 DSR 的检验水平/功效已用合成数据校准（水平 2/20@10%，
  注入边际 20/20 检出；450 选一的幸运儿 DSR=0.43，真技能 0.999）。

## 8. 已知偏差（先于运行登记）

1. **存活者偏差是本轮最大的偏差**：18 只标的是 2026 年存活的赢家。V 段
   EW18 B&H 已有 39.9% CAGR——收益端目标在此池上近乎白送，MaxDD<=20% 才是
   实质约束。QQQ 单资产对照（§5）是对该偏差的部分矫正，裁定必须并列呈现。
2. 零成本（S6）；on/id 收益流每日两次成交，成本敏感性最高，如实标注。
3. V 段 2018-2026 在前两轮（KDJ 家族）被评估过，对本家族为首次；
   S 段 2000-2017 同理。
4. 复权价、Yahoo 源，同前两轮限定。
5. 本家族无拟合参数（阈值全部先验固定），按 `/backtest-discipline` §三.1
   免 walk-forward；此设计选择牺牲自适应性换取免过拟合。

## 9. 本轮不做

杠杆（>1）、做空、反向 ETF（SQQQ/PSQ/SH 不入交易池）、小时频信号
（历史深度不足，若购数据另立预注册）、HMM/马尔可夫切换状态
（在线因果估计的实现复杂度与本轮时限不匹配，列为后续方向）、参数寻优。
