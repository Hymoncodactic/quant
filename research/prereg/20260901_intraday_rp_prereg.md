# 预注册：日内风险平价增强策略（资金效率提升，A0 空闲时段）

冻结时间：2026-09-01 01:0x（本文件落盘早于任何收益统计量的计算）
裁定：`research/decisions/20260901_intraday_rp_ruling.md`（结果产出后写）
入口：`scripts/20260901_intraday_rp_backtest.py`

## 0. 立项（用户要求，S6，2026-09-01）

1. A0 开仓频率低、资金使用效率低。构想一个**日内增强层**：美股开盘后一段时间开仓，
   15:30 前平仓，为 A0 的 15:30 决策腾出资金；A0 不开仓时可留仓过夜。
2. **本轮只回测纯日内形态**：每天开、当天收盘前平，不建模 A0 占用与过夜分支
   （留待策略合并轮）。
3. 费率取实盘档（actual）；滑点参考
   `data/reference/t212_demo_slippage_by_symbol_20260831.csv`（DEMO 实测）。
4. 配置方式：风险平价，倾向低风险资产。

## 1. 先验立场（动手前写定）

1. **成本先于信号就已经决定量级**。USD 计价工具每个往返付 30bp 换汇费 +
   约 2bp 点差 + 实测滑点。日内策略每天一个往返，年成本下限
   ≈ 252 × 33bp ≈ **8.3%/年**。
2. 美股**日内（开盘→收盘）收益基座接近零甚至为负**：本项目研究裁定
   `20260820_regime_lf_ruling.md` §3 中 id 流最佳配置 V 段 CAGR 仅 1.8%（零成本）；
   隔夜异象文献（Lou-Polk-Skouras 2019）记录日内段约 −4%/年。
   债券、黄金的日内漂移同样无正基座的文献支持。
3. 因此**预期毛收益 0±2%/年，净收益 −6% ~ −9%/年，判定为否决**。
4. 风险平价改变的是波动分配，不改变换手（每天满仓进出，成本与权重方案无关），
   **无法修复负的期望净收益**。
5. 若结果如预期为负，本轮的价值是把成本门槛量化到具体数字，并指出结构性替代
   （GBP 计价工具无换汇费；或按用户原始构想在 A0 空仓时**持仓过夜**以摊薄换手）。
6. 预期失败，失败结果同样入档（P2）。

## 3. 时序（冻结）

| 环节 | 规则 |
|---|---|
| 入场决策 | 每场次 09:30 bar（观察完开盘后第一小时） |
| 入场成交 | **10:30 bar 开盘价**（next_open 口径，避开开盘拥堵，符合用户既有裁定「不卡开盘点」） |
| 出场决策 | 14:30 bar |
| 出场成交 | **15:30 bar 开盘价**——恰在 A0 的 15:30 决策之前腾出资金 |
| 半日市 | 不入场。日历取自数据实测的无 15:30 bar 日（9 天，含 2026-01-30 与部分抓取的 2026-08-31），实盘对应交易所公布的提前收市日历 |
| 窗口 | 2023-11-16 至 2026-08-28。**修订 2026-09-01（先于任何结果）**：原定 2023-11-07，但 FX 1h 序列因 Yahoo 730 天滚动上限前移、现始于 2023-11-14，首个安全美股场次相应后移；属数据可用性约束，非结果驱动 |

持有段为 10:30→15:30，**放弃 09:30–10:30 与 15:30–16:00 两段**，这是规格自带的。

## 4. 权重（冻结，三种并列，不择优）

日频权重，t 日权重只用 ≤ t−1 的日线收盘（构建器内置 cutoff 断言）。

| 代号 | 方法 |
|---|---|
| EW | 等权 1/N |
| IVOL | 逆波动率：w_i ∝ 1/σ_i，σ_i 为 60 日日收益率标准差 |
| ERC | 等风险贡献：120 日协方差，循环迭代解 w_i·(Σw)_i 相等，确定性算法 |

满仓口径：权重和为 1，`slot_headroom 0.99` 同 A0。

## 5. 成本（冻结）

actual 档（`CostConfig.actual_tier()`，故障全关）+ 逐标的滑点：

| 项 | 值 |
|---|---|
| 换汇费 | 0.15% 每腿（框架既有） |
| 半点差 | 1.0 bp/腿（框架既有美股口径） |
| 逐标的额外滑点 | `max(0, round_trip_median_bps/2 − 1.0)`，取自滑点 CSV 的 `round_trip_median_bps` 列（该列不依赖参考价，是 CSV 自述最稳的量） |
| 未实测标的（ETF10） | 用 CSV 汇总中位 3.435bp：额外滑点 = 0.72bp/腿 |

滑点 CSV 的限定原样携带：DEMO 模拟器非实盘、每标的仅 n=3、单腿 $7 远小于实际单位。
实现方式：`CostConfig` 增 `slippage_bps_by_symbol`（缺省空字典 = 现行为，
须以字节级复现证明），符合回测纪律 §七的参数化扩展条款。

## 6. 无未来函数三件套

1. cutoff 断言：权重构建器断言所用日线日期 < 目标日。
2. 判别力探针臂：作弊臂用**当日已实现的 10:30→15:30 收益符号**过滤入场
   （明知前视），其收益须显著高于正常臂，证明检验管线能捕捉前视。
3. 特征可测性：入场决策仅用 09:30 bar（10:30 完成）及更早；出场为无条件规则。
