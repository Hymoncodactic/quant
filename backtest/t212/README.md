# 股票线（Trading 212）回测思路

接入方式见 `backtest/README.md`；本文件只讲这个市场的特有口径。
每个数值的出处见 `fixplans/framework/03/04` 与
`data/reference/t212_research_20260820/`（官方 OpenAPI 规范 + 逐条取证 JSON）。

## 1. 市场结构决定的口径

| 事实 | 回测处理 |
|---|---|
| 账户 GBP，API 下单强制主币结算 | 账本单一 GBP 现金；USD 标的每笔双边过 0.15% FX 费（以劣化汇率方式收取，与官方机制一致） |
| 伦敦标的计价混 GBp/GBP/USD | GBp = 便士（/100）；折算集中在账本层，feed 保持源单位 |
| 日线 ts = 交易所本地零点转 UTC；BST 期间伦敦标的落前一 UTC 日 23:00 | 日线对齐按**交易所本地日期**；按 UTC 日期对齐会错位一天（实证见 `docs/data/t212/DATA_SPEC.md` §3） |
| 美股 1h 在 :30 网格、伦敦在 :00 网格 | 撮合资格按时间制，交错时间轴不会提前半小时成交 |
| 美英日历不对称（如 2026-07-03） | 缺 bar 标的持仓照旧、订单排队至该市场再开 |
| T212 自身零佣金零附加点差，成交不劣于参考交易所 BBO | 成本 = 参考交易所触及点差（实测表）+ 滑点，非 T212 加价 |

## 2. 成交模型（订单四类，官方契约对齐）

- 市价：下一可成交 bar 开盘 ± 半点差 ± 滑点；闭市排队至下一开盘。
  `fill_timing="same_close"` 时改为决策 bar 收盘价 ± 半点差 ± 滑点 ± 收盘临近
  滑点（实测 P75 11bp / 中位 5bp），延迟超 60 秒或当根无 bar 则落到下一开盘。
- 限价：开盘穿限价按开盘成交；bar 内须**严格穿透**（触及不成交）；成交价不劣于限价。
- 止损：LTP 触发（触及即触发，跳空按更差的开盘价成交），触发后按市价腿执行，
  执行延迟在**触发时**抽取；触发单向持久化，部分成交余量不复验 stop。
- 止损限价：可即成腿按 stop 触及价（不给 bar 外价格）；非可即成腿要触发后
  证据（买看 low 严格穿透，卖只认 close）。
- DAY 于交易所本地午夜过期；GTC 常驻；每 ticker 挂单上限 50。

## 3. 成本表（全部带官方出处，见 fixplans/framework/04）

| 项 | 取值 |
|---|---|
| 佣金 | 0 |
| FX 费 | 0.15%（USD 标的双边；GBP/GBp 不收） |
| 印花税 SDRT | LSE 股票买入 0.5%；ETF/ETC 豁免（当前池全为 ETF/ETC） |
| PTM | 单**订单** > £10,000 收 £1.50，跨部分成交只收一次；对 ETF 是否实收未证实，默认收（保守，可配） |
| 美股卖出 | FINRA $0.000195/股 + SEC 0.00206% 卖出额 |
| 点差 | 伦敦标的用 2026-08-19 实测触及点差之半（CSPX 0.36bp ~ IBTL 8.94bp）；未实测伦敦线取最差实测上取整 9bp；美股默认 1bp（推断）；美英重叠时段（两地本地时钟判定，随 DST）之外伦敦点差 ×2（推断） |
| 滑点 | worst 档 5bp / actual 档 0 |
| 冷却期 | worst 档 2 个 bar 间隔 / actual 档 1（结构下限） |

## 4. 平台故障模拟（16 类，来源均为公开实例）

`FaultConfig` 开关全集见 `fixplans/t212_faults/01_fault_catalog.md`。要点：
随机拒单后订单**实际已受理**（重试即重复持仓，官方非幂等警告）、撤单与成交
竞态、4 位下单精度 vs 8 位持仓（卖不净留尘）、可用购买力 ≈95%×现金、
挂单占用可卖数量、延迟档位（正常秒级~20s / 拥堵 1–26 分钟折算 bar）、
中断窗口（F3/F4/F11/F14 为显式配置能力，默认空——元数据会标注
`fault_switches_armed_but_empty`，报告不得声称已施加中断压力；历史校准
窗口：2020-11-24 与 2020-12-14 IB 宕机、2021-01-27~02-02 GME/AMC 只减仓）。

## 5. 本市场特有的已知乐观偏差

1. us_equity 组含存活者偏差（Yahoo 清除退市股，见
   `research/decisions/20260821_paid_data_sources.md`）。
2. 美股开盘竞价点差未加宽（重叠窗口逻辑只覆盖伦敦标的），由 worst 档滑点
   部分吸收。
3. 1h 历史仅约 730 天（Yahoo 上限），长周期结论须以 1d 另验。
4. 复权价的股息毛额问题（框架级，见 `backtest/README.md` §7），对
   us_equity 与 VUSA 等分红线影响最大；爱尔兰累积型 UCITS（CSPX 等）近零。

## 6. 年化与日历

年化因子 252（本适配层注入，引擎无默认值）；交易日历不外接库，直接由
落地数据的 bar 存在性表达（假日/半日自动正确）。
