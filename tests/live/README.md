# `tests/live/` 目录说明

## 1. 职责

装**实盘与模拟盘的人工测试计划**：必须在真实交易时段、对着真实场所执行的
测试的规程与判据。

不装：可执行代码。本目录只有文档。会发起网络请求的测试脚本按
`CLAUDE.md` §一（`tests/` 不装发起网络请求的代码）放在 `scripts/` 下并带
日期前缀，当前是 `scripts/20260829_live_probe.py`；pytest 可收集的单元测试
在 `tests/` 的其余位置。

本目录与 `docs/backtest/validation/` 的分工：那里是回测框架自身的验证计划，
这里是**交易代码对着真实场所**的测试计划。

## 2. 文件清单

| 文件 | 作用 | 存在必要性 | 谁在用 |
|---|---|---|---|
| `01_session_test_plan.md` | 交易时段测试计划：时区对照表、模拟盘与实盘两条路线、7 项测试（T1–T7）及其判据、执行顺序、中止条件、批次一结果 | 交易时段的窗口只有 29 分钟且每日只有一次，没有预先写定的规程与判据就会在窗口内临时决定做什么，测不出成本与延迟这类需要事前定好提取方式的指标 | 人工执行；驱动脚本为 `scripts/20260829_live_probe.py` |
| `README.md` | 本文件 | | |

## 3. 子目录索引

无。

## 4. 依赖关系

本目录只被人读取，不被任何代码 import。计划中引用的对象：
`scripts/20260829_live_probe.py`（驱动脚本）、`trading212/execution/run_a0.py`
（决策与结算入口）、`trading212/config/t212.paper.yaml`（模拟盘配置）、
`logs/`（指标提取来源）、`data/t212/execution_state/`（账本与旗标）。

## 5. 产出与清理

本目录不产出运行件。测试执行产生的日志落 `logs/`，成交与流水落
`trading212/records/`，两者均 gitignore，按各自目录的规则处置。
测试结论汇总后写入 `research/decisions/` 下的裁定件，不留在本目录。
