# tests/dashboard/ 目录说明

## 1. 职责

本目录测试 Trading 212 本地看板的数据装配、只读接口、页面契约与写操作防护。
不连接真实券商，不启动实盘守护进程；文件写入全部重定向到 pytest 临时目录。

## 2. 文件清单

| 文件 | 作用 | 存在必要性 | 谁在用 |
|---|---|---|---|
| `__init__.py` | 声明测试包 | 保持 pytest 包解析稳定 | pytest |
| `test_dashboard.py` | 看板既有行为：设置、采样、账本操作、HTTP 路由与环境隔离 | 防止看板基础行为回归 | pytest |
| `test_fix_dashboard_charts.py` | B0 信号诊断、关注列表、累计损益历史及分股持仓市值页面契约 | 捕捉 B0 参数形状回归、资金流被误算成损益、旧历史图残留及分股图缺失 | pytest |

## 3. 子目录索引

无。

## 4. 依赖关系

读：`trading212/dashboard/` 生产模块与静态资源。
写：仅写 pytest 的 `tmp_path`。
被谁使用：pytest 收集器。

## 5. 产出与清理

无长期运行产物。`__pycache__/` 与仓库根 `.pytest_cache/` 为工具产物，测试后清理。
