## 1. 事实基础

1. **无官方延迟 SLA**。跨帮助中心、API 文档、执行政策 PDF 均无量化承诺，
   只有定性表述「executed as quickly as possible (usually within seconds)」
   （helpcentre 5781955715613）。此为已确认的否定性事实，非缺失。
2. 执行机制（执行政策 PDF 2022-01 版）：经 T212 自有 Systematic Internaliser
   成交的市价单按**下一个参考价更新**执行；经交易所路由的须等场所回报确认。
3. 公开 API 的实盘下单 2025-10-01 才开放（员工帖 KrisG），API 专属的
   POST→FILLED 延迟测量数据尚不存在（unresolved），须将来在 demo 环境实测。

## 2. 延迟档位（回测抽样分布）

| 档 | 触发条件 | 延迟量 | 依据 |
|---|---|---|---|
| L0 正常 | 默认 | 1–20 秒，均匀抽样 | 官方 seconds + 社区 20s 实例（2021-03，流动性一般的 LSE 股） |
| L1 拥堵 | bar 波动/量触发（F2 条件） | 1–26 分钟抽样（对数均匀，推断分布形态） | 2020-09-14 US 开盘 14/26 分钟实例；2021-01-04 5–15 分钟多例 |
| L2 宕机 | F3/F14 窗口 | 窗口内不可下单 | 2020-11-24、2020-12-14 各约 1 小时（员工帖/新闻） |
| L3 极端管制 | F4 reduce-only 窗口 | 买单多日不可用 | GME/AMC 2021-01-27~02-02（员工帖） |

「下单的最大延迟」的诚实回答：**官方无上界**；实证记录的最大常规延迟为
40 分钟（Wayfair，2020-07-22 社区实例），管制状态下无上界（数日禁开仓）。
回测权威口径按上表全开。

## 3. bar 粒度折算

延迟 d 秒折算为顺延 bar 数 `ceil(d / bar_seconds)` 后在该 bar 开盘价成交
（再叠加点差与滑点）。日线回测中 L0/L1 折算为 0 根（同一交易日内），
其效果由「下一交易日开盘成交」的基线时序覆盖——即日线模式下延迟模型只有
L2/L3 有区分度；1m/5m 回测中 L0/L1 有完整区分度。此差异写入结果元数据。

## 4. SETSqx 拍卖类标的

LSE SETSqx 段只在日内 5 次集合竞价成交（08:00/09:00/11:00/14:00/16:35 UK，
社区帖 + 员工确认），观察到 40–100 分钟等待。当前标的池无 SETSqx 标的，
不实现；若将来加入 AIM 小盘股，此为先决建模项。
