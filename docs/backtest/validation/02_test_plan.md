# 测试计划：判别力清单与复现纪律

依据：`/backtest-discipline` §六（判别力验收）、`/verified-dev` 阶段 4。
每条测试必须回答「实现若错，本测试是否失败」；答案为否的测试不算数。

## 1. 单元测试清单

测试落 `tests/backtest/`，合成数据构造在测试内部，不依赖 `data/` 真实文件
（涉及真实数据的实证检验见 §2）。

| # | 被测行为 | 判别力设计 |
|---|---|---|
| U1 | 账本金额用 Decimal 累加 | 用 0.1+0.2 类二进制不可精确表示的金额序列，float 实现将偏离 Decimal 期望值 |
| U2 | GBp 折算 /100、USD 折算 /GBPUSD | GBPUSD 取非 1 值（如 1.27）；折算方向若写反（乘除颠倒），期望值不同 |
| U3 | 下一根 bar 开盘成交 | 构造 open ≠ close 且下一根 open ≠ 当根 close 的 bar；若实现误用当根 close 或当根 open 成交，成交价不同 |
| U4 | 禁止同 bar 成交 | 在最后一根 bar 提交订单：应保持未成交而非在当根成交 |
| U5 | 数量向下取整到步进 | 样本带余数（如步进 0.1、目标 0.37 → 0.3）；四舍五入实现会得 0.4 |
| U6 | 取整后低于最小量则废弃 | 样本取整后恰低于最小量：应废单而非放行 |
| U7 | 印花税只对适用标的的买入 | 三样本对照：UK 普通股买入（收）、同标的卖出（不收）、ETF 买入（豁免）；三者结果互不相同 |
| U8 | FX 费只对非 GBP 结算 | 三样本：USD 计价（收）、GBP 计价（不收）、GBp 计价（不收）；GBp 若被误判为外币会多收 |
| U9 | 日线跨交易所对齐按本地交易日 | 样本横跨 BST 边界（2026-06-28 至 07-06 形态的合成数据）：伦敦标的 ts=23:00 UTC 前一日；按 UTC 日期对齐的实现会错位一天 |
| U10 | 日历不对称 | 合成 2026-07-03 形态：美标的无 bar、伦敦标的有 bar；美标的挂单不得成交、持仓照常估值 |
| U11 | 成本双档（最坏档 vs 实际档） | 两档参数取不同值，断言两档结果不同且最坏档更差（`/backtest-discipline` §二.4） |
| U12 | 容量上限 | 单笔超过 bar 成交量比例上限：判不可执行，不得部分外推 |
| U13 | 本金 = 峰值同时占用 | 两组样本：持仓重叠 vs 不重叠；重叠组峰值 = 两笔之和、不重叠组 = 单笔最大。实现若用累计投入或计划额度，两组区分失败 |
| U14 | 故障注入各开关 | 每种故障开/关各跑一次，断言行为差异（拒单次数、成交延迟 bar 数、成交价偏移）非零 |
| U15 | 挂单跨日有效期 | DAY 单收盘未成交即取消；GTC 单保留。两种有效期在同一序列上结果不同 |
| U16 | 引擎确定性 | 同参数重跑两次，结果文件逐字节一致（排除时间戳字段后 sha256 相同） |

## 3. 复现纪律

1. 结果文件命名：`backtest/results/<strategy>_v<M>_<m>_<p>_<arm>_<window>_<关键参数>.parquet`
   （`/quant-code-standards` §4.5.1），参数进文件名。
2. 引擎改动后基线重跑，与既有结果逐字节 `cmp`（`/backtest-discipline` §七.2）。
   基线结果文件不含运行时间戳，保证可比。
3. 每轮回测的完整配置（含故障开关状态、成本档、随机种子）序列化进结果元数据；
   结果文件缺配置即判不可用。
4. 随机性（故障注入的抽样）一律走显式种子的 `numpy.random.Generator`，
   种子进结果元数据与文件名。

## 4. 审查回归测试（2026-08-20 增补，落 `tests/backtest/test_review_regressions.py`）

| # | 被测行为 | 判别力设计 |
|---|---|---|
| U17 | 结果文件字节级重跑一致（写盘两次 sha256 相同） | 含时间戳或非确定序列化的实现两次哈希必不同 |
| U18 | 混交易所日内网格无前视：:30 网格决策的订单不得在 30 分钟后的 :00 bar 成交 | 步数制资格在 15:00 成交、时间制在 16:00，两种实现结果不同 |
| U19 | F11 / F12 / F14 开关行为差 | 各开关开/关两跑，拒单结果不同 |
| U20 | STOP 触发单向持久化 | 触发 bar 被成交量上限截断后，下一 bar 价格已离开 stop 区间仍须按市价腿成交；复验 stop 的实现无成交 |
| U21 | PTM 按订单累计只收一次 | 三笔部分成交各自 < £10k、累计 > £10k：按单收 1 次 £1.50，按笔收 0 次 |
| U22 | 止损限价撮合语义 | 可即成腿按 stop 触及价（旧实现给出 bar 外价格）；卖侧非可即成腿只认 close 证据（旧实现采信触发前的 high） |
| U23 | 重叠窗口随 DST | 冬令时 14:00 UTC（美未开盘）与 16:00 UTC（重叠中）两样本，固定 UTC 窗实现两个都错 |
| U24 | 引擎目标数量落到场所精度 | 目标 1/3 股在 F8 开启下成交 0.3333 股，无 precision 拒单循环 |
